# 🎓 Student Management System

A web-based **Student Management System** developed using **PHP** and **MySQL**. This application allows an administrator to manage student records through a secure login system and complete CRUD (Create, Read, Update, Delete) operations.

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/umeshnath23/student-management-system.git
```

2. Move the project to the XAMPP `htdocs` folder.

3. Start **Apache** and **MySQL**.

4. Create a database named:

```
student_db
```

5. Import the `student_db.sql` file using phpMyAdmin.

6. Update database credentials in:

```
config/database.php
```

7. Open your browser and visit:

```
http://localhost/student-management-system/
```
